# Slides

The deck of the webinar "Claude Code Black Belt", built with [Slidev](https://sli.dev). Slides in
English, notes in German. The notes under each slide explain it, so the deck reads on its own.

```bash
npm install
npm run dev      # http://localhost:3030, notes at /presenter/
npm run export   # PDF in dist/
```

`styles/`, `layouts/` and the components `D07HarnessLoop`, `D09PermissionGate`, `DocLink`,
`G03CarelessVsEngineered` and `JourneyMap` come from the slides of the course Mastering Claude Code.
